# AP/STI Bridge — Concurrent WiFi for Arduino UNO Q

Configure your UNO Q's single WiFi radio to simultaneously:
- Stay connected to your home WiFi network (Station mode)
- Broadcast its own access point for worker devices (AP mode)

Both run on different channels. Your SSH connection stays alive the whole time.

---

## Quick Start

1. **Open `index.html` in any browser** (Chrome, Firefox, Safari, Edge — no server needed)
2. **Fill in the form:**
   - Home WiFi SSID and password
   - Worker AP name, password, and channel
   - Your UNO Q's wlan0 MAC address (find with `ip link show wlan0`)
3. **Click "Generate Config Files"**
4. **Download the files** (or copy individually)
5. **Copy to your UNO Q:**
   ```bash
   scp -r ap_sti_bridge/ arduino@uno-q:/home/arduino/
   ```
6. **On the UNO Q, run:**
   ```bash
   sudo bash /home/arduino/ap_sti_bridge/scripts/ap0-up.sh
   ```
7. **Verify:**
   ```bash
   ip link show wlan0 ap0
   ping -c 3 8.8.8.8
   ```

That's it. The AP is live. Connect your worker devices to the AP SSID you configured.

---

## What It Does

The UNO Q's WCN3990 radio supports virtual interfaces. This tool:

- Creates `ap0` as a second virtual interface on the same physical radio (`phy0`)
- Runs `wlan0` (station) on your home router's channel
- Runs `ap0` (AP) on a different fixed channel
- Keeps both interfaces active simultaneously
- Bridges the MCU's TCP server to the network (optional)
